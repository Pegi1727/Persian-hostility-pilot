# Owner release checklist — unresolved factual checks
- [ ] Confirm author names, affiliations, corresponding contact, and public repository URL; complete CITATION.cff accordingly.
- [ ] Confirm permission/consent or an appropriate basis for public distribution of pseudonymous ratings and stimulus texts. Pseudonymization is not guaranteed anonymity.
- [ ] Supply truthful ethics approval/exemption/not-required explanation as applicable; do not invent an approval number.
- [ ] Document recruitment, Persian proficiency, independence procedures, compensation (if any), training, and guideline scale anchors.
- [ ] Confirm what annotators saw, whether intended labels were hidden, and how item order was set. Do not claim verified randomization/blinding without records.
- [ ] Confirm provenance of pilot texts separately from AI-revised candidate provenance.
- [ ] Confirm UTC interpretation of the administrative timestamp correction.
- [ ] Review canonical-versus-legacy p-values in results and update manuscript consistently; normal approximations must not be called exact.
- [ ] Select licenses after rights review; currently none is granted.
- [ ] Ensure every in-text citation has a verified bibliography entry and vice versa. Incomplete Hada and Mapping references require completion; do not publish invented metadata.
- [ ] Link the final manuscript and final supplement only after their factual and statistical review.
- [ ] Run all commands in README in a fresh environment and confirm checksums before tagging a public release.

This package intentionally avoids invented recruitment details, ethics statements, ORCIDs, funding, preregistration, code/data licenses, model scores, repository URLs, and publication DOIs.
