# Provenance and version boundaries
The owner supplied completed files `all_annotations_filled_v031.csv`, `analysis_ready_v031.csv`, three individual filled annotator CSVs, and ancillary completion/validator summaries. Earlier blank v03 forms are templates, not completed data. This package uses the filled analysis-ready file, cross-checked against the consolidated and individual files.

The owner explicitly confirmed that the ratings were provided by humans. CSV consistency checks cannot independently establish human authorship, annotator independence, recruitment, or consent. Some original free-text notes used wording translated as “generated response”; that wording has not been reinterpreted as proof of machine authorship or silently edited in the originals.

The original timestamps indicated 20 November 2026. Following an owner correction request, all response timestamps were set to 10 November 2026, 18:00, retaining the source UTC convention. The user did not separately specify a timezone. Thus the UTC interpretation must be confirmed before using this metadata in any narrative. The common time is not observed per-response timing and cannot support duration or sequence claims. Originals and the full timestamp change log are retained outside this public package because the log contains administrative record-level information.

Public preparation removed notes, evidence, timestamps, session identifiers, presentation order, and unused supplementary fields. No published ratings or category responses were edited. The filename tag v031 is a packaging/processing identifier; the recorded guideline and stimulus versions remain pilot-0.3. It is not evidence of a new annotation round.

The 320-text candidate v2.1 set is a separate, AI-revised, not-human-validated development product. Candidate and pilot IDs are not interchangeable. Candidate files and the private candidate key are excluded, not silently relabelled as validated pilot data.
